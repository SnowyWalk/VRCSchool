## 설치 방법
![](./images/img.png)
<Steps>
    <Step>
        ALCOM (또는 VCC) 실행
    </Step>
    <Step>
        '패키지 & 템플릿' > 'VPM 저장소' > 'VPM 저장소 추가' 클릭
    </Step>
    <Step>
        저장소 정보 입력 칸에 아래의 주소 입력

        ```
        https://vrc.community/packages/com.vrchat.vpm.modular-avatar/
        ```
    </Step>
    <Step>
        아래의 설명을 따라 패키지 추가
    </Step>
</Steps>
